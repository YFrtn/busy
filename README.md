# Busy

**Приложение для скачивания видео и аудио — для Windows и macOS.**

Вставьте ссылку с YouTube, TikTok, Instagram, Twitter/X и 1000+ других сайтов — скачайте видео в MP4 или звук в MP3, M4A, FLAC, WAV. Плюс выгрузка медиа из Telegram-каналов и нарезка длинных аудиофайлов на части.

Всё работает локально на вашем компьютере: никаких серверов, регистрации и загрузки ваших файлов куда-либо.

## Скачать и установить

Есть два пути: **готовое приложение** (проще, ничего не надо знать про Python) и **установка из исходников** (одна команда в терминале, всегда свежая версия).

### 🪟 Windows 10/11

**Готовое приложение**

1. Откройте страницу [**Releases**](https://github.com/YFrtn/busy/releases/latest) и скачайте файл `Busy-windows-x64.zip`.
2. Распакуйте архив в любую папку — например, в `C:\Program Files\Busy` или прямо на рабочий стол.
   Распаковать нужно **целиком**: `Busy.exe` не работает отдельно от соседних файлов.
3. Запустите `Busy.exe`.
4. Windows покажет синее окно **«Система Windows защитила ваш компьютер»** — это обычное предупреждение для программ без платной подписи Microsoft. Нажмите **«Подробнее»** → **«Выполнить в любом случае»**.
5. При первом запуске Busy сам предложит скачать **FFmpeg** (около 80 МБ) — нажмите «Установить» и подождите. Без него видео не склеится в MP4, а аудио не превратится в MP3.

Чтобы приложение было под рукой: правой кнопкой по `Busy.exe` → «Закрепить на панели задач».

**Установка из исходников** (нужен интернет; Python поставится автоматически)

Откройте **PowerShell** и выполните:

```powershell
irm https://raw.githubusercontent.com/YFrtn/busy/main/install.ps1 | iex
```

Скрипт поставит Python (если его нет), скачает код в `%LOCALAPPDATA%\Busy\src`, скачает FFmpeg и создаст ярлыки на рабочем столе и в меню «Пуск».

### 🍎 macOS 11+

**Готовое приложение**

1. Определите тип процессора: меню  → «Об этом Mac».
   - **Apple M1/M2/M3/M4** → скачайте `Busy-macos-arm64.zip`
   - **Intel** → скачайте `Busy-macos-x86_64.zip`

   Оба файла лежат на странице [**Releases**](https://github.com/YFrtn/busy/releases/latest).
2. Распакуйте архив и перетащите `Busy.app` в папку **«Программы»**.
3. Приложение не подписано платным сертификатом Apple, поэтому macOS сначала откажется его открывать («Busy повреждён» или «не удалось проверить разработчика»). Снимите карантин — один раз, в Терминале:

   ```bash
   xattr -dr com.apple.quarantine /Applications/Busy.app
   ```

4. Установите FFmpeg (нужен для видео и конвертации звука):

   ```bash
   brew install ffmpeg
   ```

   Нет Homebrew? Поставьте его командой с [brew.sh](https://brew.sh) — или используйте установку из исходников ниже, она сделает всё сама.

5. Запуск: **⌘ + Space** → наберите «Busy».

**Установка из исходников — одна команда**

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/YFrtn/busy/main/install.sh)"
```

Скрипт установит Homebrew-зависимости (`python3`, `ffmpeg`, `tdl`), скачает код в `~/.busy`, создаст виртуальное окружение и положит `Busy.app` в «Программы». Карантин снимать не нужно — приложение собирается у вас на компьютере.

### 🐧 Linux

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/YFrtn/busy/main/install.sh)"
```

Тот же скрипт: ставит `python3`, `ffmpeg` и WebKitGTK через `apt`/`dnf`, добавляет Busy в меню приложений. Если нативное окно недоступно, приложение просто откроется во вкладке браузера.

## Как пользоваться

Окно приложения разделено на четыре вкладки.

### Скачать

1. Скопируйте ссылку на видео (YouTube, TikTok, Instagram, X, Reddit, Vimeo, Twitch, SoundCloud…).
2. Вставьте её в поле — ссылку можно и просто перетащить мышкой в окно.
3. Выберите режим:
   - **Видео** — MP4, можно выбрать качество от 360p до 4K;
   - **Аудио** — MP3, M4A, FLAC, WAV, AAC, OPUS с битрейтом от 64k до 320k.
4. Нажмите «Скачать». Прогресс, скорость и оставшееся время видны прямо в окне.

Можно вставить **несколько ссылок сразу** — они скачаются одна за другой. Плейлист распознаётся автоматически: приложение предложит выбрать, какие ролики забрать.

### Telegram

Выгрузка медиа из чатов и каналов, к которым у вас есть доступ. Требуется утилита `tdl`.

1. Нажмите «Войти через QR» — появится QR-код.
2. В телефоне: Telegram → Настройки → Устройства → «Подключить устройство» → отсканируйте код.
3. Выберите чат и что именно скачать: всё, только видео, только фото, документы, аудио или текст сообщений.

Файлы раскладываются по папкам: `Загрузки/Имя канала/video`, `/photo`, `/documents`, `/text`.

### Нарезка

Перетащите длинный аудиофайл (лекция, подкаст, диктофонная запись) — Busy порежет его на части примерно по 20 минут в формате `.m4a`. Удобно, когда файл нужно отправить туда, где есть ограничение на длительность или размер.

### История

Все скачанные файлы с поиском. Кнопка рядом с записью открывает файл в Finder (macOS) или Проводнике (Windows). Историю можно чистить по одной записи или целиком.

## Что нужно доустановить и зачем

При первом запуске Busy показывает экран проверки — там видно, что уже стоит, а что нет, и есть кнопка «Установить».

| Инструмент | Зачем | Обязателен |
|---|---|---|
| **FFmpeg** | Склейка видео со звуком, конвертация в MP3/FLAC/WAV, нарезка аудио | Да |
| **yt-dlp** | Собственно скачивание с сайтов | Да (входит в комплект) |
| **Homebrew** | Менеджер пакетов, через который на macOS ставится всё остальное | Только macOS |
| **tdl** | Скачивание из Telegram | Нет — только для вкладки Telegram |

Как это устроено на разных системах:

- **Windows** — FFmpeg Busy скачивает сам в `%LOCALAPPDATA%\Busy\bin`, права администратора не нужны. Если есть `winget`, используется он.
- **macOS** — всё ставится через Homebrew: `brew install ffmpeg`, `brew install telegram-downloader`.
- **Linux** — `apt`/`dnf`/`pacman`.

**yt-dlp стоит обновлять**: сайты постоянно меняются, и старая версия перестаёт скачивать. На экране зависимостей у yt-dlp есть кнопка «Обновить» — нажимайте её, если что-то вдруг перестало работать.

## Куда сохраняются файлы

- Скачанное — в системную папку **«Загрузки»**.
  Изменить: задайте переменную окружения `BUSY_DOWNLOAD_DIR` с нужным путём.
- История и служебные данные:
  - Windows — `%LOCALAPPDATA%\Busy`
  - macOS — `~/Library/Application Support/Busy`
  - Linux — `~/.local/share/busy`

Ничего не уходит в интернет, кроме запросов к самим сайтам, с которых вы скачиваете.

## Обновление

**Готовое приложение** — скачайте новый архив со страницы [Releases](https://github.com/YFrtn/busy/releases/latest) и замените файлы. История и настройки сохранятся.

**Установка из исходников** — просто запустите установщик ещё раз, он подтянет свежую версию:

```bash
# macOS / Linux
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/YFrtn/busy/main/install.sh)"
```

```powershell
# Windows
irm https://raw.githubusercontent.com/YFrtn/busy/main/install.ps1 | iex
```

---

## Удаление

**Windows:** удалите папку с `Busy.exe`, ярлыки, а также `%LOCALAPPDATA%\Busy`.
**macOS:** удалите `/Applications/Busy.app`, папки `~/.busy` и `~/Library/Application Support/Busy`.
**Linux:** удалите `~/.busy`, `~/.local/share/busy` и `~/.local/share/applications/busy.desktop`.

## Решение проблем

**Windows: «Система Windows защитила ваш компьютер»**
Приложение не подписано платным сертификатом. «Подробнее» → «Выполнить в любом случае». Антивирус иногда ругается на PyInstaller-сборки по той же причине — это ложное срабатывание; при желании соберите приложение сами (см. ниже).

**macOS: «Busy повреждён и не может быть открыт»**
Сработал карантин для скачанных из интернета неподписанных приложений. Выполните:
```bash
xattr -dr com.apple.quarantine /Applications/Busy.app
```

**«FFmpeg не найден» / скачивается только звук без картинки**
FFmpeg не установлен. Windows: экран зависимостей → «Установить». macOS: `brew install ffmpeg`. После установки нажмите «Проверить снова».

**Видео не скачивается, ошибка вроде «Sign in to confirm you're not a bot» или «Unable to extract»**
Обычно устарел yt-dlp: экран зависимостей → у yt-dlp кнопка «Обновить». YouTube меняет защиту довольно часто, поэтому обновление помогает в большинстве случаев.

**Окно приложения пустое / не открывается**
На Windows нужен компонент **WebView2** (он есть во всех актуальных Windows 10/11; если нет — [скачайте Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)). Если окно всё равно не появляется, Busy автоматически откроется в браузере.

**Порт занят**
Busy сам возьмёт свободный порт. Задать вручную: переменная окружения `PORT`.

**Telegram: «TDL не установлен»**
macOS: `brew install telegram-downloader`. Windows: `winget install tdl` или [бинарник со страницы релизов tdl](https://github.com/iyear/tdl/releases). Вкладка Telegram — необязательная часть, остальное работает и без неё.

## Для разработчиков

### Запуск из исходников

```bash
git clone https://github.com/YFrtn/busy.git
cd busy
python3 -m venv venv
./venv/bin/pip install -r requirements.txt   # Windows: venv\Scripts\pip install -r requirements.txt
./venv/bin/python busy.py                    # Windows: venv\Scripts\python busy.py
```

Или короче: `./run.sh` (macOS/Linux), `Busy.bat` (Windows).
Флаг `--browser` открывает интерфейс во вкладке браузера вместо нативного окна.

### Сборка приложения

```bash
pip install pyinstaller
pyinstaller Busy.spec --noconfirm --clean
```

Результат — `dist/Busy.app` (macOS) или `dist/Busy/Busy.exe` (Windows). Тот же спек используется в GitHub Actions: `.github/workflows/build.yml` собирает Windows-, Intel- и Apple Silicon-версии на каждый тег `v*`.

### Как устроено

| Часть | Технология |
|---|---|
| Окно приложения | pywebview — WKWebView (macOS), WebView2 (Windows), WebKitGTK (Linux) |
| Бэкенд | Python + Flask, слушает только `127.0.0.1` |
| Фронтенд | Один HTML-файл, без сборки и фреймворков |
| Скачивание | [yt-dlp](https://github.com/yt-dlp/yt-dlp) + [FFmpeg](https://ffmpeg.org) |
| Telegram | [tdl](https://github.com/iyear/tdl) |

Всё, что различается между операционными системами — пути, открытие папок, запуск процессов, установка зависимостей — собрано в одном файле [`platform_utils.py`](platform_utils.py).

### Безопасность

- Сервер поднимается только на `127.0.0.1`, снаружи недоступен.
- Ссылки проверяются: localhost и приватные диапазоны IP блокируются.
- Ограничение частоты запросов, автоочистка временных файлов.
- Показывать в файловом менеджере можно только пути внутри папки загрузок.
